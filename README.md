# 学生成绩管理系统

一个用 C++ 写的命令行成绩管理工具，外加一个可视化的网页看板。

核心逻辑在 C++ 里（录入、修改、删除、统计、排名、导出），网页只负责把结果画得好看。
两者用一份 `data.js` 连接，不需要服务器，双击网页就能打开。

## 功能

**C++ 端**
- 录入学生（学号、姓名、三门课成绩），自动查重
- 查看全部、按平均分排名
- 修改成绩（不想改的科目输 -1 跳过）
- 删除学生（带确认）
- 班级统计：平均分、最高/最低、全科及格率、各科平均分
- **自动存档**：数据写在 `students.txt`，关掉程序下次打开还在
- 导出 `grades.csv`（Excel 可打开）和 `web/data.js`（网页读取）

**网页端**
- 概览数字卡片（人数、班级平均分、最高总分、及格率）
- 成绩明细表（前三名用颜色标记）
- 平均分对比条形图

## 运行方法

**1. 编译**

双击 `build.bat`。它会调用 Visual Studio 的编译环境，成功后生成 `grade.exe`。

**2. 运行**

双击 `run.bat`，或直接双击 `grade.exe`。

**3. 看网页**

菜单里选 `7` 导出数据，然后双击 `web/index.html`。

## 文件结构

```
grade-system/

├── build.bat         一键编译脚本
├── run.bat           运行脚本

└── web/

    └── data.js       由 C++ 自动生成的数据（勿手改）
```

## 三个设计说明

**为什么网页读的是 `data.js` 而不是 `data.json`**

浏览器直接用 `file://` 打开网页时，读取 `.json` 会被同源策略拦住（CORS），
而 `<script src="data.js">` 属于加载脚本，不受这条限制。
所以让 C++ 直接生成一个 `var STUDENTS = [...]` 的 js 文件，是不需要起服务器的最简方案。

**为什么命令行表格不用 `setw` 对齐**

一个中文字符的显示宽度是英文字母的两倍，`setw` 按字符数补空格永远对不齐。
所以改成「一行一个学生」的标签式输出，中英混排都不会歪。

**为什么要写输入保护**

用户在输入数字的地方打了字母，`cin` 会进入错误状态，
之后所有输入全部失效、程序陷入死循环。
所以读数字统一走 `readInt` / `readDouble`，失败就 `clear()` + `ignore()` 兜底。

## 技术点

- `struct` 组织数据，`vector` 存多个学生
- `sort` + lambda 表达式做排名
- `ofstream` / `ifstream` 文件读写（存档 + 导出）
- 输入流状态处理（`cin.clear()` / `cin.ignore()`）
- 跨语言数据交换：C++ 生成数据 → 前端直接消费
